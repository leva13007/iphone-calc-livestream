# IPhone calculator: React + TypeScript + Vite

![stream_06.png](stream_06.png)

Цей репозиторій — результат стріму 1 травня 2025 року, де в прямому ефірі ми:

- ⚛️ писали калькулятор на **React + TypeScript**
- 🤯 замінили `eval()` на власну реалізацію **Shunting Yard Algorithm**
- 💡 додали підтримку `sqrt()`, `^`, дужок, унарних операторів
- 🎨 зробили сучасну адаптивну верстку під стилістику iPhone
- 🧪 говорили про безпеку, парсинг, асоціативність та стекові обчислення
